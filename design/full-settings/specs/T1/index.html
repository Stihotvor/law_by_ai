    T1: Settings properties, helper, docstring table, unit tests¶

    Context¶

    Later features (Qdrant search, local rerank, confidence filter, observability) read their configuration from Settings. The charter replaced Cohere with a local rerank model, so the three Cohere keys must go. This task changes settings.py and its unit tests. It serves the business goals and the Edge Cases and Failure Modes of requirements.md.

    Technical Approach¶

    Path 1 of decision.md: extend the plain class. Each value is a property that reads os.getenv on each access.

    In src/config/settings.py: - Remove the properties rerank_base_url, rerank_api_key, rerank_model and their three rows in the module docstring table. Before the removal, run grep -rnE 'rerank_base_url|rerank_api_key|rerank_model\b' src tests. Discovery found no reader outside src/config/settings.py. Stop and report if a reader exists. - Add a helper _float_in_range(name, default, low, high), next to _int_at_least. An unset or empty value gives the default. A value that has only whitespace raises ValueError. It strips surrounding whitespace, then converts to float. It rejects a non-number, nan, inf, and a value outside low..high (both ends valid). Every error message names the variable. - Add 8 properties with these env keys and defaults: - qdrant_url = QDRANT_URL, http://localhost:6333 (plain string, no scheme check) - qdrant_api_key = QDRANT_API_KEY, empty - qdrant_collection = QDRANT_COLLECTION, legal_documents - otel_exporter_otlp_endpoint = OTEL_EXPORTER_OTLP_ENDPOINT, empty (empty means export off) - otel_service_name = OTEL_SERVICE_NAME, law-by-ai - min_confidence = MIN_CONFIDENCE, 0.5, uses _float_in_range(..., 0.0, 1.0) - rerank_model_name = RERANK_MODEL_NAME, empty - rerank_model_path = RERANK_MODEL_PATH, empty - For string keys, an empty variable uses the default. Settings never fail on an empty RERANK_MODEL_NAME or RERANK_MODEL_PATH. - Do not add rerank_enabled. - Rename the section header "LLM / embeddings / reranking (ADR-0014)" to match the new content. Put the Qdrant, OTel, min_confidence and rerank model properties under clear headers. - Update the docstring table: add the 8 new rows and the missing MIGRATION_LOCK_TIMEOUT_S row (default 300). - No secret value in an error message. QDRANT_API_KEY has no validation, so no message names its value.

    In tests/unit/config/test_settings.py: - Add the 8 new keys to _ENV_KEYS. - Add a default test and an override test for each of the 8 keys (at least 16 cases). - Add MIN_CONFIDENCE rejection cases (abc, -0.1, 1.1, nan, inf, " ") that check ValueError and that the message contains MIN_CONFIDENCE. Add accept cases (0, 1, 0.5) and an empty-value case. - Add a test that Settings has none of rerank_enabled, rerank_base_url, rerank_api_key, rerank_model. - Add test_old_rerank_keys_do_no_harm: with RERANK_BASE_URL, RERANK_API_KEY and RERANK_MODEL set, reading the 8 new properties raises no error.

    Acceptance Criteria¶

    Scenario Outline: A new key uses its default when unset
  Given the environment variable <key> is not set
  When the code reads <property> on a new Settings
  Then the value equals <default>
  Examples:
    | key                         | property                    | default                 |
    | QDRANT_URL                  | qdrant_url                  | http://localhost:6333   |
    | QDRANT_API_KEY              | qdrant_api_key              |                         |
    | QDRANT_COLLECTION           | qdrant_collection           | legal_documents         |
    | OTEL_EXPORTER_OTLP_ENDPOINT | otel_exporter_otlp_endpoint |                         |
    | OTEL_SERVICE_NAME           | otel_service_name           | law-by-ai               |
    | MIN_CONFIDENCE              | min_confidence              | 0.5                     |
    | RERANK_MODEL_NAME           | rerank_model_name           |                         |
    | RERANK_MODEL_PATH           | rerank_model_path           |                         |

Scenario Outline: A new key takes the environment value
  Given the environment variable <key> is set to <value>
  When the code reads <property>
  Then the value equals <expected>
  Examples:
    | key                         | property                    | value                | expected             |
    | QDRANT_URL                  | qdrant_url                  | qdrant:6333          | qdrant:6333          |
    | QDRANT_API_KEY              | qdrant_api_key              | k1                   | k1                   |
    | QDRANT_COLLECTION           | qdrant_collection           | c1                   | c1                   |
    | OTEL_EXPORTER_OTLP_ENDPOINT | otel_exporter_otlp_endpoint | http://alloy:4317    | http://alloy:4317    |
    | OTEL_SERVICE_NAME           | otel_service_name           | svc                  | svc                  |
    | MIN_CONFIDENCE              | min_confidence              | 0.8                  | 0.8                  |
    | RERANK_MODEL_NAME           | rerank_model_name           | bge-reranker         | bge-reranker         |
    | RERANK_MODEL_PATH           | rerank_model_path           | /models/rerank       | /models/rerank       |

Scenario: Empty MIN_CONFIDENCE uses the default
  Given MIN_CONFIDENCE is set to an empty string
  When the code reads min_confidence
  Then the value is 0.5

Scenario Outline: MIN_CONFIDENCE rejects a bad value
  Given MIN_CONFIDENCE is set to <value>
  When the code reads min_confidence
  Then a ValueError is raised
  And the error message contains "MIN_CONFIDENCE"
  Examples:
    | value |
    | abc   |
    | -0.1  |
    | 1.1   |
    | nan   |
    | inf   |
    | "   " |

Scenario Outline: MIN_CONFIDENCE accepts a valid value
  Given MIN_CONFIDENCE is set to <value>
  When the code reads min_confidence
  Then the value equals <expected>
  Examples:
    | value   | expected |
    | 0       | 0.0      |
    | 1       | 1.0      |
    | " 0.5 " | 0.5      |

Scenario: The Cohere settings are gone
  Given a Settings instance
  Then it has no attribute rerank_enabled, rerank_base_url, rerank_api_key or rerank_model
  And the command grep -riE 'cohere|rerank_base_url|rerank_api_key' src/config returns 0 lines

Scenario: A developer .env cannot change the default tests
  Given the 8 new keys are listed in _ENV_KEYS
  When the default tests call _clear_env
  Then every one of the 8 keys is removed from the environment

    Definition of Done¶

    • The task's done_when check passes.
    • Tests exist for every scenario and pass.
    • The quality gate reports pass or skipped (never fail).
    • No OPEN: item remains.
