# T2: citations core module

## Context
Answers need source links and a confidence score. A low score gives "no reliable answer" and the closest sources (ADR-0008, ADR-0015). This task builds the pure module that scores hits and decides. It serves the scoring, threshold, no-citation and edge-case items in `requirements.md`. It depends on T1 for the notice.

## Technical Approach
Create `src/core/citations.py`. Stdlib and `src.core.notices` only. No environment read, no I/O. The module docstring documents the scoring rule.

Names and signatures from `decision.md`:
- `RETRIEVAL_WEIGHT = 0.4` and `RERANK_WEIGHT = 0.6` (named constants, provisional).
- `@dataclass(frozen=True) class ScoredHit`: `source_url: str`, `quote: str`, `retrieval_score: float`, `rerank_score: float | None`, and optional `law`, `article`, `paragraph`, `document_id`.
- `@dataclass(frozen=True) class Citation`: the same fields, with one `confidence: float` in place of the two scores.
- `@dataclass(frozen=True) class Answer`: `citations`, `confidence`, `notice`.
- `@dataclass(frozen=True) class NoReliableAnswer`: `closest_sources`, `notice`. It has no `citations` and no `confidence`.
- `def decide(hits, min_confidence: float) -> Answer | NoReliableAnswer`.

Rules:
- Validate `min_confidence` in [0, 1], else `ValueError`.
- Validate each score: the bool check runs first, then NaN, infinity and range [0, 1]. The `ValueError` message names the field (`retrieval_score`, `rerank_score`, `min_confidence`).
- Confidence = retrieval score when rerank is `None`, else `RETRIEVAL_WEIGHT * retrieval + RERANK_WEIGHT * rerank`.
- Drop hits whose URL is empty, not http(s), or holds credentials (userinfo). Use `urllib.parse`.
- Sort valid hits by confidence descending (stable sort keeps input order on ties).
- Keep hits with confidence `>= min_confidence`. If any remain: `Answer(citations, confidence=max, notice=NOT_LEGAL_ADVICE_NOTICE)`.
- Otherwise `NoReliableAnswer(closest_sources=<top 3 valid hits>, notice=NOT_LEGAL_ADVICE_NOTICE)`. An empty list or no valid hit gives empty `closest_sources`.
- Callers branch with `match`.

Resolved (lead, no design change): decision.md does not give the container types for `Answer.citations` and `NoReliableAnswer.closest_sources`, the element type of `closest_sources` (`Citation` assumed), the type of `hits` (`Sequence[ScoredHit]` assumed), or the validation point for a score on a hit that is later dropped for its URL (assumed: validate every hit first). Proposed: `tuple[Citation, ...]` for both fields. Decided: tuple[Citation, ...] for both fields, Sequence[ScoredHit] for hits, every hit validated before the URL filter.

Tests in `tests/unit/core/test_citations.py`, including an import test that checks the module imports only stdlib and `src.core.notices` (no sqlalchemy, httpx, requests, redis, celery, openai).

## Acceptance Criteria
Scenario: valid citations
  Given four or more hit sets with valid http(s) URLs and scores in [0, 1]
  When `decide` returns an `Answer`
  Then every citation has a valid `source_url` and a confidence in [0, 1]

Scenario: threshold boundaries
  Given a hit with confidence 0.5 and `min_confidence` 0.5
  When `decide` runs
  Then the result is `Answer`
  And with confidence 0.49 and `min_confidence` 0.5 the result is `NoReliableAnswer`
  And with confidence 0.4 and `min_confidence` 0.3 the result is `Answer`

Scenario: no citation
  Given an empty hit list, or hits that all have invalid URLs
  When `decide` runs
  Then the result is `NoReliableAnswer` with empty `closest_sources`

Scenario: URL filter
  Given hits with an empty URL, a non-http(s) URL and a URL with credentials
  When `decide` runs
  Then none of them appears in any result

Scenario: scoring rule
  Given a hit with no rerank score
  When it is scored
  Then confidence equals the retrieval score
  And with both scores confidence equals 0.4 * retrieval + 0.6 * rerank
  And `RETRIEVAL_WEIGHT + RERANK_WEIGHT == 1.0`

Scenario: bad input
  Given a bool, NaN, infinity or out-of-range score, or `min_confidence` outside [0, 1]
  When `decide` runs
  Then it raises `ValueError` whose message names the field

Scenario: order and limits
  Given several valid hits with equal and different confidence
  When `decide` returns `Answer`
  Then `citations` are sorted by confidence descending, stable on ties
  And `Answer.confidence` is the maximum
  And `closest_sources` of a `NoReliableAnswer` holds at most 3 items

Scenario: shared notice
  Given any result of `decide`
  When `notice` is read
  Then it equals `NOT_LEGAL_ADVICE_NOTICE`

Scenario: no I/O imports
  Given the module `src/core/citations.py`
  When the import test inspects its imports
  Then only stdlib and `src.core.notices` appear
