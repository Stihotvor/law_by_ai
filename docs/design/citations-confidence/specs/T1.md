# T1: NOT_LEGAL_ADVICE_NOTICE constant

## Context
Every answer must carry one shared "not legal advice" notice (ADR-0015). The bureaucracy agent and the citation UI import it and do not copy it. This task serves the "shared notice" goal and the notice failure mode in `requirements.md`.

## Technical Approach
- Create `src/core/notices.py` with one module constant: `NOT_LEGAL_ADVICE_NOTICE: str`.
- The text is English, non-empty, and holds the phrase "not legal advice".
- The module has no imports and no logic.
- Create `tests/unit/core/test_notices.py`. It asserts the type is `str`, the value is non-empty, and `"not legal advice" in NOT_LEGAL_ADVICE_NOTICE.lower()`.

## Acceptance Criteria
Scenario: the notice is a non-empty string
  Given the module `core.notices`
  When the test imports `NOT_LEGAL_ADVICE_NOTICE`
  Then `isinstance(NOT_LEGAL_ADVICE_NOTICE, str)` is true
  And `NOT_LEGAL_ADVICE_NOTICE.strip()` is not empty

Scenario: the notice says it is not legal advice
  Given the constant `NOT_LEGAL_ADVICE_NOTICE`
  When the test lowercases the text
  Then the text contains "not legal advice"

Scenario: the module is fully covered
  Given `tests/unit/core/test_notices.py`
  When pytest runs with `--cov=core.notices --cov-fail-under=100`
  Then the run passes

## Definition of Done
- `.venv/bin/pytest tests/unit/core/test_notices.py` passes, and with `--cov=core.notices --cov-fail-under=100` it passes.
- Tests exist for every scenario and pass.
- The quality gate reports pass or skipped (never fail).
- No `OPEN:` item remains.
