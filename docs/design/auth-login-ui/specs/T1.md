# T1: Pin pyjwt exactly in pyproject.toml

## Context
`src/ui/components/auth.py` imports `jwt` to catch `jwt.PyJWTError`. PyJWT is only a transitive dependency of streamlit-authenticator 0.4.2. The requirements decide to declare `pyjwt` as a direct, exact pin like the other pins. This closes the dependency drift gap.

## Technical Approach
- Read the version that streamlit-authenticator 0.4.2 resolves now: `.venv/bin/python -m pip show pyjwt`.
- Add `pyjwt==<that version>` to the runtime dependencies in `pyproject.toml`, in the style of the other exact pins.
- Run `uv pip install --python .venv/bin/python -e ".[dev]"`, then `.venv/bin/pip-audit`.
- Make no change to `src/`. If the pin conflicts with streamlit-authenticator or `pip-audit` fails, stop and report (decision.md, Consequences).

## Acceptance Criteria
```gherkin
Scenario: pyjwt is a direct exact dependency
  Given pyproject.toml before the change has no direct pyjwt entry
  When the pin is added
  Then `grep -n 'pyjwt==' pyproject.toml` prints one line with an exact version

Scenario: the pin resolves
  Given the pin is in pyproject.toml
  When `uv pip install --python .venv/bin/python -e ".[dev]"` runs
  Then the command exits 0

Scenario: the pin has no known vulnerability
  Given the dev environment is installed
  When `.venv/bin/pip-audit` runs
  Then it exits 0
```
