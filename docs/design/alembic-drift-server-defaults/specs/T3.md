# T3: Pin CHECK name with conv() and add naming-convention unit test

## Context
Alembic compares CHECK constraints by name only. A future `naming_convention` with a `%(constraint_name)s` ck token would rename `ck_legal_document_status`. This task pins the name and adds a test that fails with a clear message. It serves the requirement "keep the exact CHECK name".

## Technical Approach
- In `src/data/models.py`, change the CheckConstraint name to `conv("ck_legal_document_status")` (import `conv` from `sqlalchemy.sql.elements` or `sqlalchemy`). The DDL name stays byte-identical to migration `963e40b83003`.
- In `tests/unit/test_data_models.py`, add `test_check_name_survives_naming_convention`. Build `MetaData(naming_convention={"ck": "ck_%(table_name)s_%(constraint_name)s"})`. Copy `legal_document` into it with `Table.to_metadata`. Compile the CHECK name (for example with `CreateTable` on the PostgreSQL dialect) and assert it is exactly `ck_legal_document_status`.
- Keep `test_check_constraint_definition_and_validated` in `tests/integration/test_document_status_migration.py` (the `pg_get_constraintdef` test) unchanged as the guard of the CHECK text.

## Acceptance Criteria
