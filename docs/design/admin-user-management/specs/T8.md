# T8: Quality gate and coverage and mutation check

## Context
The repo requires a full quality gate and coverage and mutation gates before a task is done. This task runs them on the new code and fixes gaps. It serves the success metric on gates.

## Technical Approach
No source file is listed. Run from the repo venv: `ruff check`, `ruff format --check`, `pyright`, `pytest -m "not integration"`. Run the coverage commands in the "Coverage and mutation gates" section of CONTRIBUTING.md (the mutation gate is scoped to `src/agents/fetch` in `pyproject.toml` and does not cover `src/core/users`, so it does not apply) for `src/core/users`. Fix findings in the files of T1 to T7 and add tests for surviving mutants. Mutation runs in CI only. Do not relax any gate.

## Definition of Done
- The task's `done_when` check passes.
- Tests exist for every scenario and pass.
- The quality gate reports pass or skipped (never fail).
