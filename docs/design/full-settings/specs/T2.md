# T2: Env example, compose block and drift test

## Context
An operator reads `docker/.env.example` and the compose `x-app-env` block to learn the keys. Cohere keys there would mislead them, and the 8 new keys must be visible. This task serves the business goal "no Cohere key in `docker/.env.example`" and the success metrics on grep counts and the drift test. It depends on T1, because the drift test reads the `Settings` docstring table.

## Technical Approach
In `docker/.env.example`:
- Remove `RERANK_BASE_URL`, `RERANK_API_KEY`, `RERANK_MODEL` (lines under the embedding keys).
- Add the 8 new keys with their defaults: `QDRANT_URL=http://localhost:6333`, `QDRANT_API_KEY=`, `QDRANT_COLLECTION=legal_documents`, `OTEL_EXPORTER_OTLP_ENDPOINT=`, `OTEL_SERVICE_NAME=law-by-ai`, `MIN_CONFIDENCE=0.5`, `RERANK_MODEL_NAME=`, `RERANK_MODEL_PATH=`. Use short comments. State that an empty OTel endpoint means export off.
- Fix the header comment "LLM / embeddings / reranking" so it does not promise a remote rerank service.

In `docker/docker-compose.yml`, block `x-app-env`:
- Remove `RERANK_BASE_URL:`, `RERANK_API_KEY:`, `RERANK_MODEL:`.
- Add the 8 new keys as bare keys (`NAME:`), the style of the neighbouring optional settings.
- `grep -c 'RERANK_' docker/docker-compose.yml` must print 2.

New file `tests/unit/config/test_settings_drift.py`:
- One parametrized test over the 8 new keys. For each key, check that it appears in the `config.settings` module docstring table, in `docker/.env.example` (as `KEY=` or `# KEY=`) and in the `x-app-env` block of the compose file.
- Parse the compose file with a YAML load (or a bounded text search of the `x-app-env` block). Use `ROOT_DIR` from `config.settings` to find the files.
- The test covers the 8 new keys only. Older keys stay out of scope.

In `src/config/plugins.yaml`, delete only the commented-out `reranking`/`cohere` block, so the issue acceptance grep on `src/config` returns 0 lines. Do not touch `RerankingPlugin`. `src/config/.env.example` does not exist. The PR text says so.

Decided: a bare `QDRANT_URL:` key is acceptable. Compose passes the host value through, and an unset value gives the default. The search issue adds the Qdrant service and sets the container URL.
